# Mula logo prospects

All five concepts use flat clay (#CF947A), charcoal (#171B1E), and the approved rounded wordmark.

Each folder contains a full logo, transparent full logo, standalone symbol, and square app icon as SVG and PNG. All logo lettering is vector outlines.

## 1. Horizon
A stronger evolution of the striped sunrise.

## 2. First Light
A clear sunrise, with five deliberate rays.

## 3. Threshold
An open doorway to a new beginning.

## 4. Rising M
A sunrise paired with a distinctive M monogram.

## 5. Radiant
A geometric fan of first light.
